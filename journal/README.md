# Experience Journal

Tracking the experience of building and managing a website entirely through Claude Code — for a thesis on whether CMS systems are still needed.

## How to write an entry

1. Read this file to find the last entry number and date
2. Review the conversation since the last entry to reconstruct:
   - What the user wanted (intent, in their own words where possible)
   - Exact prompts given (quote verbatim)
   - What Claude Code did (tools, files, commands)
   - What worked and what didn't (friction, retries, surprises)
   - Outcome — what was produced, did it meet the goal
3. Capture the user's casual remarks, reactions, opinions — authentic voice is gold for the thesis
4. Write reflections connecting what happened to the thesis question: if an LLM can do this, what does it mean for CMS platforms?
5. Create the next numbered file in `journal/` (e.g., `002-short-title.md`) following existing entry format
6. Update the table below with the new entry
7. If the user added casual notes, weave them into the reflections
